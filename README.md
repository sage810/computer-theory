- 과목별 주소: `#ds` 자료구조, `#algo` 알고리즘, `#os` 운영체제

## 내용요소에 자료 연결하기

`index.html`에서 해당 내용요소 줄을 찾아 두 군데를 고칩니다.

```html
<!-- 전 -->
<span class="name">트리 응용</span> ... <span class="soon">준비 중</span>
<!-- 후 -->
<a class="name" href="ds/tree-apps/">트리 응용</a> ...   (준비 중 태그는 지움)
```

제목줄의 `자료 0 / 58` 숫자도 함께 올립니다.
