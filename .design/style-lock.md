# Style Lock — computer theory

이 파일이 있으면 3단계(톤·색·타이포 도출)를 다시 하지 않고 아래 값을 그대로 재사용한다. 방향을 바꾸고 싶다는 명시적 요청이 있을 때만 갱신한다.

## 배포 방식

- 방식: GitHub Pages (main 브랜치 루트를 그대로 배포, 빌드 없음)
- 주소: https://sage810.github.io/computer-theory/
- 확인일: 2026-11-21

## 목적·사용자

- 목적: 자료구조·알고리즘·운영체제의 과목 → 영역 → 내용요소 목록 (선생님 본인 임용 공부용)
- 정보 밀도: 중간~높음 (3과목 · 13영역 · 내용요소 56개)
- 격식/친근함: 중간 (참고 사이트의 친근한 레트로 겉모습 + 차분한 목차 배치)
- 사용 빈도: 반복 사용 (자주 들어와 찾아보는 목차)

## 타이포

- 본문 폰트: 넥슨 Lv2 고딕 400 (`fonts/NEXONLv2Gothic-Regular.subset.woff2`, KS X 1001 2350자, 넥슨 무료 글꼴), 대체: Apple SD Gothic Neo, Malgun Gothic — 키워드·세부내용·안내·개수
- 굵은 글씨: Maplestory 700 (`fonts/`) — 내용요소 이름·탭 개수·버튼. 본문 글꼴은 400 파일만 두었으니 굵게 쓰지 않는다
- 제목·번호 폰트: CookieRun 700 (`fonts/`)
- Maplestory 300 은 메모 창(tools/memo.js)만 쓴다
- 한글 줄바꿈: body 에 `word-break:keep-all`, 이름·안내·세부내용은 `text-wrap:pretty`
- 기본 크기: 내용요소 16px, 세부 항목 14px, 영역 제목 19px, 과목 제목 26px

## 레이아웃 구조

- 선택한 틀: 레트로 창 하나 안에 맨 위 과목 탭(한 번에 한 과목, 주소 `#ds`/`#algo`/`#os`) + '세부내용 모두 펼치기' 버튼 → 과목 머리 → 영역별 트리 개요
- 트리 개요: 영역 아래 세로 안내선(3px)에서 가지선이 뻗어 내용요소 `1.1.1`, 키워드는 `#태그`, 세부내용은 접고 펴는 버튼(`details`) 안에 `└` 줄
- 탭·세부내용 버튼 높이 44px 이상(휴대폰), 스크립트가 없으면 세 과목 모두 보임
- 노트 페이지(`ds|algo|os/번호/index.html`): 첫 화면과 같은 틀 — 창 최대 1040px, 제목줄(사이트 이름 + 부제), 과목 탭(첫 화면으로 가는 링크, 지금 과목은 눌린 모양), 머리는 과목 머리 상자 모양(큰 번호 + 이름 + 오른쪽 위치), 키워드·세부내용은 첫 화면과 같은 모양, 공부 칸 제목은 영역 제목처럼 CookieRun 21px + 왼쪽 3px 세로 안내선, 빈 칸은 '준비 중'과 같은 점선 꼬리표, 아래 이전·목차·다음. 공통 모양 `assets/note.css`
- 노트 본문: 소제목 h3(Maplestory 700 18px)·h4(16px 보조색), 용어는 `<strong>`(Maplestory 700), 원본과 다르게 고친 곳은 `.fix`(분홍 점선 꼬리표 `#a3356b`), 표 머리칸은 과목 연한 색
- 목차에서 노트가 있는 내용요소: 이름이 링크(연한 2px 밑줄 `--guide`, 마우스를 올리면 잉크색), '준비 중' 꼬리표 없음
- 여백: 4px 단위
- 선택 이유: 엑셀에 세부내용 칸이 생겨 사용자가 D/E/F 시안 중 "겉모습은 현재 그대로 + F의 트리 개요 + E의 과목 전환·접고 펴기"로 골라 합침
