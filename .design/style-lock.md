# Style Lock — computer theory

이 파일이 있으면 3단계(톤·색·타이포 도출)를 다시 하지 않고 아래 값을 그대로 재사용한다. 방향을 바꾸고 싶다는 명시적 요청이 있을 때만 갱신한다.

## 배포 방식

- 방식: GitHub Pages (main 브랜치 루트를 그대로 배포, 빌드 없음)
- 주소: https://sage810.github.io/computer-theory/
- 확인일: 2026-11-21

## 목적·사용자

- 목적: 자료구조·알고리즘·운영체제의 과목 → 영역 → 내용요소 목록 (선생님 본인 임용 공부용)
- 정보 밀도: 중간~높음 (3과목 · 13영역 · 내용요소 56개)
- 격식/친근함: 중간 (참고 사이트의 친근한 레트로 겉모습 + 차분한 목차 배치)
- 사용 빈도: 반복 사용 (자주 들어와 찾아보는 목차)

## 타이포

- 본문 폰트: 넥슨 Lv2 고딕 400 (`fonts/NEXONLv2Gothic-Regular.subset.woff2`, KS X 1001 2350자, 넥슨 무료 글꼴), 대체: Apple SD Gothic Neo, Malgun Gothic — 키워드·세부내용·안내·개수
- 굵은 글씨: Maplestory 700 (`fonts/`) — 내용요소 이름·탭 개수·버튼. 본문 글꼴은 400 파일만 두었으니 굵게 쓰지 않는다
- 제목·번호 폰트: CookieRun 700 (`fonts/`)
- Maplestory 300 은 메모 창(tools/memo.js)만 쓴다
- 한글 줄바꿈: body 에 `word-break:keep-all`, 이름·안내·세부내용은 `text-wrap:pretty`
- 기본 크기: 내용요소 16px, 세부 항목 14px, 영역 제목 19px, 과목 제목 26px

## 레이아웃 구조

- 선택한 틀: 레트로 창 하나 안에 맨 위 과목 탭(한 번에 한 과목, 주소 `#ds`/`#algo`/`#os`, 내용요소 줄은 `#i-1-2-3`) → 과목 머리 → 영역 상자마다 표(시안 D)
- 영역 표(시안 D): 영역 상자(3px 잉크 테두리, 그림자) 머리는 과목 연한 색 + 오른쪽 개수 꼬리표, 칸 머리 `번호 | 내용요소 | 세부내용`(64px · 1.15fr · 1fr), 줄 사이 구분선 없음(사용자 피드백), 키워드는 과목 색 테두리 꼬리표, 세부내용은 오른쪽 칸에 늘 보임(왼쪽 2px 점선), 없으면 `—`. 640px 이하에서는 세부내용이 이름 아래로
- 탭 높이 44px 이상(휴대폰), 스크립트가 없으면 세 과목 모두 보임
- 왼쪽 고정 목차(첫 화면 + 노트 공통, `assets/sidebar.css`·`sidebar.js`): 창과 같은 모양의 288px 패널(제목줄 그라데이션), 과목 › 영역을 `details` 로 접고 폄(열린 과목은 과목 색), 내용요소는 노트가 있으면 과목 색 점 + 진한 글씨, 영역 노트에서 지금 화면에 보이는 내용요소는 연한 색 바탕. 1000px 이상은 본문 왼쪽 고정(접으면 왼쪽 위 '목차' 버튼만, 이 브라우저에 기억), 그보다 좁으면 왼쪽 아래 '목차' 버튼으로 여는 서랍
- 노트 페이지(영역마다 한 장, `ds|algo|os/영역번호/index.html`): 첫 화면과 같은 틀 — 창 최대 1040px, 제목줄(사이트 이름 + 부제), 과목 탭(첫 화면으로 가는 링크, 지금 과목은 눌린 모양), 머리는 과목 머리 상자 모양(큰 영역 번호 + 영역 이름 + 오른쪽 과목·내용요소 수). 그 아래 내용요소가 쭉 이어짐: 번호·이름 띠(과목 연한 색 바탕, 3px 잉크 테두리, 그림자 4px, CookieRun 21px, 휴대폰 19px) + 키워드·세부내용(첫 화면과 같은 모양) + 공부 칸, 내용요소 사이 64px(휴대폰 48px), 공부 칸 제목은 영역 제목처럼 CookieRun 21px, 칸은 선 없이 넓은 칸 사이 여백(48px, 휴대폰 40px)과 내용 들여쓰기(24px, 휴대폰 16px)로 묶음(시안 G), 칸 제목은 칸 왼쪽 끝에서 한 글자(1em) 들어가 시작, 빈 칸은 '준비 중'과 같은 점선 꼬리표, 아래 이전·목차·다음 영역. 공통 모양 `assets/note.css`
- 노트 본문: 칸 제목 h3 와 용어 `<strong>` 은 넥슨 Lv2 고딕 Bold 700, 목록 본문(li)은 KoPub World 돋움 Medium 500 (`fonts/KoPubWorldDotum-Medium.subset.woff2`), 문단·표는 넥슨 Regular 400 (`fonts/NEXONLv2Gothic-{Regular,Bold}.subset.woff2`). 소제목 h4·h5 는 Maplestory 700, 원본과 다르게 고친 곳은 `.fix`(분홍 점선 꼬리표 `#a3356b`, 400), 표 머리칸은 과목 연한 색
- 노트 칸(2026-11-21~): 칸은 보통 하나, 칸 이름 = 내용요소 이름(또는 원고의 주제 제목). 내용은 글머리 목록 하나 — 첫 단계 굵은 묶음, 글머리는 단계마다 • ◦ ▪ – (Word 원고와 같음)
- 목차에서 노트가 있는 내용요소: 이름이 링크(연한 2px 밑줄 `--guide`, 마우스를 올리면 잉크색), '준비 중' 꼬리표 없음
- 여백: 4px 단위
- 선택 이유: 엑셀에 세부내용 칸이 생겨 사용자가 D/E/F 시안 중 "겉모습은 현재 그대로 + F의 트리 개요 + E의 과목 전환·접고 펴기"로 골라 합침 → 다시 사용자가 "목차도 시안 D로, 과목 탭은 유지" + 왼쪽 고정 목차를 요청
