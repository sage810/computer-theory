# 피드백 모드 (수정 요청 메모)

화면에서 **고칠 곳을 직접 가리켜 요청을 남기면** Claude 가 그 요청대로 `index.html` 을 고치는 기능.
middle school info 의 피드백 모드(`shared/runtime/msi-memo.js`)를 이 저장소(빌드 없음, 첫 화면 하나)에 맞게 옮긴 것이다.

- 선생님 전용. 주소 끝에 `?memo=1` 을 붙이지 않으면 아무것도 하지 않는다.
- 이 PC 미리보기(8090)에서는 요청이 `.claude/feedback.md` 에 바로 쌓인다. GitHub Pages 에서는 복사·붙여넣기로 보낸다.

## 1. 켜기

| 방법 | 하는 일 |
|---|---|
| Claude 에게 **"피드백 모드"** 또는 **"메모 켜줘"** | 아래 `npm run memo` 를 대신 실행 |
| 과목을 함께 말하기: "알고리즘 피드백 모드" | 그 과목 탭으로 연다 (`ds` · `algo` · `os`) |
| 터미널: `npm run memo -- algo` | 미리보기 서버(8090)가 꺼져 있으면 뒤에서 켬 → `http://127.0.0.1:8090/?memo=1#algo` 를 브라우저로 연다 |

- 끄기: 주소 끝을 `?memo=0` 으로 바꿔 연다. 서버는 끌 필요 없다.
- 한 번 `?memo=1` 로 열면 그 브라우저가 기억한다.
- 8090 인 까닭: middle school info 의 미리보기 서버가 8080 을 쓴다. 둘을 같이 켜도 섞이지 않는다.
- 원격(다른 Tailscale 기기): `npm run memo` 가 `http://<Tailscale 주소>:8090/?memo=1` 도 찍는다. 안 열리면 Windows 방화벽이 8090 을 막는 것 — 선생님 허락을 받고 규칙을 둔다(아직 없음).

## 2. 쓰는 법

1. 오른쪽 아래 **📝 메모** 를 누른다.
2. 고칠 곳을 고른다 (둘 중 하나, 안 골라도 된다).
   - **🎯 요소 고르기** → 마우스를 올린 곳에 분홍 점선 테두리 → 클릭. 고르는 동안 탭·세부내용 버튼은 반응하지 않는다. **Esc** 로 취소.
   - 글을 **드래그**해서 선택.
3. 어떻게 고칠지 적고 **📤 보내기** → `.claude/feedback.md` 에 쌓인다.
4. 창 안 목록에 아직 처리 전인 요청이 보인다. **✕** 로 지울 수 있다.
5. 여러 곳을 보낸 뒤 Claude 에게 **"피드백 처리해줘"**.

GitHub Pages 주소에서 켜면 "📤 보내기" 대신 **➕ 목록에 담기 → 📋 전체 복사 → Claude 대화에 붙여넣기** 다. 이 목록은 그 브라우저에만 있다(localStorage).

## 3. 기록 형식 (`.claude/feedback.md`)

```
## 2026. 11. 21. 15:02:11 · / 「컴퓨터 이론 공부 노트」
- 종류: 메모
- 요소: span.name                         ← 🎯 요소 고르기로 골랐을 때
- 위치: 알고리즘 › 2.2 알고리즘 설계원리 › 2.2.5 되추적 › 세부내용
- 선택한 글: "백트래킹의 작동 원리"
- 메모: 예시 문제 이름도 넣어줘
- 화면: 1280×860
- 상태: [ ] 처리 전
```

- 처리하면 `- 상태: [x] 처리됨 — 무엇을 어느 파일에서 했는지 한 줄`.
- 이 파일은 `.gitignore` 에 있다(공개 저장소).

## 4. Claude 가 처리하는 순서

1. `.claude/feedback.md` 의 `[ ]` 항목을 읽는다. 세션을 시작할 때 `[ ]` 가 있으면 먼저 알린다.
2. `index.html` 에서 **위치의 번호(예: `2.2.5`)와 선택한 글**로 Grep 해서 고칠 줄을 찾는다. 요소 이름은 보조.
   - 제목 줄 페이지가 `/ds/1-2/` 처럼 영역 노트 주소면 그 폴더의 `index.html` 을 고친다(요소 이름의 `#n-1-2-4` 가 내용요소). 모든 노트에 해당하는 모양이면 `assets/note.css`. 공부 칸 글을 고치는 요청이면 Word 원고(`노트 원고/…/1-2 ….docx`)도 맞출지 묻는다.
3. **요청한 범위만 최소 diff** 로 고친다(Edit). 모호하면 고치기 전에 묻고 `[ ]` 로 둔다.
   - 내용요소·세부내용 글을 바꾸는 요청이면, 원본 `example1.xlsx` 와 달라진다는 점을 한 줄로 알린다.
4. "밋밋해", "더 보기 좋게"처럼 느낌·판단인 요청은 바로 고치지 않고 후보 2~3개를 먼저 보인다. 기준은 `.design/style-lock.md`.
5. 미리보기(8090)를 새로고침해 화면으로 확인하고, 항목을 `[x]` + 한 줄로 닫는다.
6. 항목별로 고친 것·못 고친 것을 짧게 알린다. 사이트에 반영하려면 커밋·push 가 필요하다는 것도 알린다.

## 5. 구성 파일

| 파일 | 역할 |
|---|---|
| `tools/memo.js` | 화면 쪽. `?memo=1` 일 때만 켜짐. 요소 고르기·글 선택·위치 찾기(과목 › 영역 › 내용요소)·보내기/복사. `index.html` 맨 아래에서 불러오고, GitHub Pages 에도 같이 올라간다 |
| `scripts/serve.mjs` | 미리보기 서버(8090). 사이트에 올라가는 것(`index.html` · `fonts/` · `tools/` · `assets/` · 노트 `ds/` `algo/` `os/`)만 보여 준다(메모·설정·엑셀은 안 보임). `/__feedback` — GET 처리 전 목록 · POST 추가 · DELETE 처리 전 항목 지우기. 주소는 127.0.0.1·localhost·이 PC 의 Tailscale 주소만, Origin 은 같은 곳만, 쓰기는 JSON 만(아니면 403·415) |
| `scripts/memo.mjs` | `npm run memo` — 서버 켜기·브라우저 열기 |

## 6. 문제 해결

| 증상 | 확인 |
|---|---|
| 📝 메모 버튼이 없다 | 주소 끝에 `?memo=1` 이 있는지 |
| "📤 보내기" 대신 "목록에 담기"가 보인다 | GitHub Pages 주소이거나, 8090 서버가 꺼져 있다. `npm run memo` 로 다시 켠다 |
| 보내기를 눌렀는데 "보내지 못했어요" | 미리보기 서버가 꺼졌다. `npm run memo` |
| "8090 포트를 이미 쓰는 프로그램" | 작업 관리자에서 남아 있는 node 를 끄고 다시 |
