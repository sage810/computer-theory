# AGENTS_MAP

이 프로젝트에서 쓴 스킬과 서브에이전트를 기록합니다.

## 사용 중

| 스킬/에이전트 | 쓴 곳 |
|---|---|
| project-housekeeping | GitHub push 전 마무리 (지도 문서 생성·갱신) |
| design-system | 첫 화면 index.html 디자인 (시안 → 빌드 → 품질 점검 → 기록) |
| Artifact Design 캔버스 | 첫 화면 시안 A/B/C 비교 |

## 추천받았지만 쓰지 않은 것

| 스킬/에이전트 | 쓰지 않은 이유 |
|---|---|
| web-design-guidelines | 사용자가 마무리를 요청해 이번엔 돌리지 않음. 다음에 원하면 실행 |
